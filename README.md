# Veiga Vibration Analyzer

Aplicativo Python/Streamlit para FFT, PSD, GRMS e comparação de vibração rodoviária.

## Execução

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Referências incorporadas

- ASTM D4728-06 — Appendix X1, Table X1.1, perfil Truck.
- ISO 13355 — perfil reproduzido no Appendix X1, Table X1.3 da ASTM D4728-06.
- ISTA 3E (2005) — Random Vibration Spectrum.

O ranking de "mais semelhante" é uma métrica matemática de comparação espectral e não constitui declaração de conformidade normativa.
